## Tools you can inspect and use

[**Mission Control: local snapshot importer**](https://github.com/vladprosper/mission-control-demo)

A Python and SQLite utility for importing JSON or CSV snapshots, rejecting inconsistent batches, skipping duplicate records, and reporting stale or missing observations. The CLI and Python API work independently of the browser demonstration. No service accounts or third-party Python packages are required.

For example, import a normalized export from an editorial tracker, replay the file without replacing unchanged records, and query the current state through a SQL view. The contract separates planned, drafted, scheduled, submitted, and verified records. These are source assertions with structural checks, not proof that an external action succeeded.

[Importer guide](https://github.com/vladprosper/mission-control-demo/blob/main/docs/IMPORTER.md) · [Schema](https://github.com/vladprosper/mission-control-demo/blob/main/docs/SCHEMA.md) · [Recorded test results and limits](https://github.com/vladprosper/mission-control-demo/blob/main/docs/TEST_RESULTS.md)

The repository also includes a fictional workflow walkthrough and a disposable preview/apply workbench. Neither runs agents, calls publishing platforms, or provides a production approval service.
